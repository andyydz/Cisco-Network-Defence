# Cisco Network Defense

A collection of Cisco Network Defense course notes and practical security examples covering network access control, defense-in-depth principles, network threats, and secure network devices.

This repository combines structured learning notes with practical work that applies network-defense concepts in a simulated environment.

## Practical Case Study

### Bank Secure Network

A Cisco Packet Tracer simulation demonstrating VLAN segmentation, inter-VLAN routing, and router ACLs for a fictional bank branch.

The case study documents the network design, access-control objectives, verified connectivity tests, limitations, and areas that still require testing.

- [Read the case study](./Practical-Case-Studies/Bank-Secure-Network.md)
- [Explore the full Bank Secure Network project](https://github.com/andyydz/bank-secure-network)

> **Scope:** This is an educational simulation and personal portfolio project, not a production banking network.

## Learning Focus

- Network segmentation and VLANs
- Access control lists (ACLs)
- Defense-in-depth principles
- Network threats and defensive controls
- Secure network-device configuration
- Security policies and operational concepts
- Validation of configured security controls

## Documentation Approach

The notes summarize concepts learned through Cisco Network Defense coursework. Practical examples distinguish between controls that were configured, behaviors that were verified, and tests that remain outstanding.

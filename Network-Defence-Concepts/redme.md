#  Network Defense Concepts

##  Overview

This repository contains my study notes, practical labs, and hands-on exercises completed as part of the **Cisco Networking Academy – Network Defense** course.

The course focuses on the fundamental concepts of network security, defensive strategies, threat identification, security monitoring, and Security Operations Center (SOC) practices used to protect enterprise networks.

---

##  Objectives

- Understand network defense fundamentals
- Learn Defense in Depth principles
- Identify assets, threats, and vulnerabilities
- Study enterprise security policies
- Analyze security logs
- Explore network monitoring techniques
- Develop practical SOC and Blue Team skills
- Gain hands-on experience with Cisco Packet Tracer

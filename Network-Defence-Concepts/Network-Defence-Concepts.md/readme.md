# Module 01 – Defense in Depth

## Overview

This module introduces the fundamental principles of network defense and the layered security approach known as **Defense in Depth**. It covers how organizations identify, classify, and protect critical assets while understanding vulnerabilities, threats, security policies, and compliance requirements. The module also includes introductory hands-on activities using Cisco Packet Tracer.

---

# Learning Objectives

After completing this module, I was able to:

- Understand the Defense in Depth security model
- Identify organizational assets and classify them based on business value
- Differentiate between threats, vulnerabilities, and risks
- Understand the lifecycle of organizational assets
- Interpret operating system and application logs
- Understand the importance of configuration management
- Learn the role of protocol analyzers in network monitoring
- Explain organizational security and BYOD policies
- Understand regulatory compliance requirements
- Document enterprise security issues using real-world scenarios
